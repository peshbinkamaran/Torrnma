# تۆڕنما | TORRNAMA V4

**دروستکەر:** پێشبین کامەران  
**بە سەرپەرشتی:** م. دانا حەسەن

## چۆن پڕۆژەکە بکەرەوە؟

1. فایلی ZIP ـەکە Extract بکە.
2. فۆڵدەری `torrnama-v4` بکەرەوە.
3. فایلی `index.html` بە Chrome بکەرەوە؛ بۆ ئەپکردن و API باشترە بە VS Code / Live Server یان Netlify بڵاو بکرێتەوە.
4. لە سەرەوە ٣ بەش هەیە: پرۆتۆکۆلەکان، تاقیگەی 3D و پانێڵی دەستکاری.

## تایبەتمەندییەکان

- ٢١ پرۆتۆکۆل لەگەڵ ڕوونکردنەوەی سۆرانی و ئینگلیزی، OSI، Sequence، Packet Flow و فێرکاری.
- هێڵکارییە تایبەتەکان بە ڕووکارێکی isometric / 3D-style بۆ پرۆتۆکۆلە جیاوازەکان: کڕیار بە لاپتۆپ، ڕاوتەر، سێرڤەر، DNS، فایەروۆڵ و ...
- دوگمەکانی Play / Pause / Step / Replay؛ دوگمەکانی گۆڕینی زمان، ڕەنگی شەو و ڕۆژ، گەڕان و ڕێنمایی.
- تاقیگەی سیموڵەیشن بۆ زیادکردنی ئامێر، ڕاکێشان، پەیوەندی دروستکردن و ڕێڕەوی Ping / DNS / HTTP.
- پاشەکەوتکردنی تاقیگە لە Browser، هەڵگرتن و هاوردەکردنی JSON.
- بەشی دەستکاریکردنی دەقی کوردی و ئینگلیزی و هەڵگرتنی local draft و export/import JSON.
- لۆگۆی نێردراوی بەکارهێنەر، PWA manifest و icon بۆ خستنە سەر home screen.
- دوو API ـی ڕاستەقینە: Google DNS-over-HTTPS (DNS) و JSONPlaceholder (HTTP). پێویستیان بە ئینتەرنێت هەیە؛ هەموو پرۆتۆکۆلەکانی تر شبیه‌سازیی فێرکارین.

## تێبینیی زۆر گرنگ لەبارەی پانێڵی بەڕێوەبردن

**ئەمە پانێڵی Admin ـی پارێزراوی گشتی نییە.** لە وەشانی V4دا «پانێڵی بەڕێوەبردن» تەنها دەستکاریکەرێکی ناوخۆییە. گۆڕانکارییەکان لە LocalStorage ـی هەمان Browser هەڵدەگیرێن؛ هەموو سەردانیکەران نایانبینن. لە Netlify ـدا تەنها بە Update/Deploy کردنی فایلە ڕاستەقینەکان دەبنە گۆڕانکاریی گشتی. بۆ دەستکاریکردنی ئۆنلاین تەنها لەلایەن خاوەنەکەوە، پێویستە backend و authentication و database ـیەکی پارێزراو دامەزرێنرێت.

**ئاگاداری:** هیچ password یان API secret ـێک لە فایلەکانی HTML / JavaScript مەنووسە. کۆدی Frontend بۆ هەموو سەردانیکەران خوێندنەوەپێکراوە.

## بڵاوکردنەوە لەسەر هەمان لینکی Netlify

1. لە Netlify بە هەژماری خۆت بچۆژوورەوە.
2. هەمان Project/Site ـی کۆنت بکەرەوە (پڕۆژەیەکی نوێ مەسازێنە).
3. بچۆ بۆ Deploys و فۆڵدەری `torrnama-v4` (ئەو فۆڵدەرەی `index.html` ـی لە سەرەوەیە) upload بکە.
4. بە deploy ـی وەشانی نوێ هەمان URL دەمێنێتەوە.
5. بۆ وەشانی ئەپ (PWA) لە Chrome کردنی ماڵپەڕ → Install app / Add to home screen تاقی بکەوە (دەکرێت پێویستی بە HTTPS و Browser ـی هاوگونجاو هەبێت).

## جیاوازی سیموڵەیشن لە داتای ڕاستەقینە

- هێڵکاریی 3D ـەکە isometric SVG ـە؛ 3D ـی گرافیکی ڕاستەقینەی Three.js نییە.
- Ping و DNS و HTTP لە **تاقیگەی 3D** تەنها packet path simulation ـن و داواکاریی ڕاستەقینە نەنێرن.
- بەشەکانی **Live API** لە ڕووکاری پرۆتۆکۆلی DNS/HTTP داواکاری ڕاستەقینە دەنێرن.
- زمان و مۆدی ڕەنگ و تاقیگەی local بە Browser تۆمار دەکرێن.

### نوێکردنەوەی ئەنیمەیشنی سیگناڵ (بە بنەمای V4)
- هێڵی داواکاری و وەڵام لە دوو ڕێڕەوی جیاوازدا پیشان دەدرێن.
- خاڵە سەوزەکە بە هێواشی دەجووڵێت، و تەنها هێڵی پشت خاڵەکە ڕەنگ دەگرێت.
- ناوی پەیام و وردەکارییەکەی لەگەڵ خاڵەکە دەجووڵێت.
- دوگمەی خێرایی: 0.75×، 1× (ئاسایی هێواش)، 1.5×، 2×.
- بۆ نوێکردنەوەی Netlify، فۆڵدەری `torrnama-v4` بۆ هەمان پڕۆژە بار بکە؛ ئەگەر وەشانی کۆنت دیار بوو، Refresh بکە.
